# 表演可视化 · Acting for AI

**把情绪、人物关系和潜台词，转化为镜头里看得见的动作。**

[English](README.en.md) · [浏览资料](docs/INDEX.md) · [技能接入](docs/INTEGRATION.md) · [方法说明](docs/METHOD.md) · [引用](CITATION.cff)

Acting for AI 是一个面向 AI 视频、动画和导演分镜的开放表演参考库。它把“隐忍”“心虚”“想靠近又犹豫”等创作意图，展开为眼神、呼吸、手部、身体重心、空间关系和动作节拍，供创作者与各类 AI 技能按需检索、组合和改写，让提示词更清楚地表达想要的表演效果。

**这套资料已由作者在实际创作中验证并持续使用。** 本仓库公开可复用的方法、动作条目与文字示例；完整视频案例暂不附带。作者实践经验不等同于逐条、全模型或量化对照评测，具体测试范围见[验证说明](docs/VALIDATION.md)。

## 从一句情绪，到一段可见表演

原始意图：**她想靠近，但要先确认对方是否愿意。**

> 她向前挪了一小步，在伸手前停住，目光先落在对方脸上。对方没有后退，转过身把手递到她面前，她才抬手接住，两人的距离随之缩短。

这个文字示例把“想靠近”落到了停步、视线确认、对方回应和距离变化。使用时替换人物与环境，并遵守你的剧本事实；无需照搬动作。相关条目：[请求许可／等待同意](docs/cards/REL-030.md)。

## 五分钟开始使用

1. 在[资料索引](docs/INDEX.md)按情绪、关系或动作问题选择条目。
2. 补齐当前人物的处境、目标和触发事件。
3. 选一个主动作，搭配必要的眼神、呼吸或空间回应。
4. 把“触发 → 判断 → 行动 → 回应／余波”写进你原有的分镜或视频提示词。
5. 结合景别、时长、参考素材和人物性格调整幅度。

不需要 API Key、生成服务或特定模型。支持读取 Markdown 或 JSON 的技能、Agent、知识库与提示词工作流，可以通过本地文件或仓库链接接入；是否能读取链接取决于接入工具自身的能力。

## 给技能与工具开发者

- 阅读入口：[docs/INTEGRATION.md](docs/INTEGRATION.md)
- 轻量检索：[data/index.json](data/index.json)
- 完整数据：[data/catalog.json](data/catalog.json)
- 唯一可编辑条目源：`cards/*.json`
- 单条原始数据示例：[REL-030.json](cards/REL-030.json)
- 离线搜索：`python scripts/library.py search "许可"`
- 英文关键词示例：`python scripts/library.py search "restraint"`（英文别名覆盖部分条目）
- Agent 可读取的检索结果：`python scripts/library.py search "permission" --category relationship --format json`

本库提供表演参考，不接管接入技能的角色、结构、权限或生成流程，也不预设视频模型的输出格式。接入后仍由你的技能完成情境判断与模型适配。
