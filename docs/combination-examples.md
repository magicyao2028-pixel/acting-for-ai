# 情绪组合文字示例

继承作者资料库 0.1.10 的组合写法。这些是文字参考；资料库方法已由作者实际使用验证，不将每段文字标为独立视频测试。



| 目标状态 | 组合方式 | 输出方向 |
|---|---|---|
| 强忍怒火 | 愤怒 + 隐忍 | 下颌、手指、低声、胸口余波 |
| 苦笑 | 悲伤 + 冷笑 | 嘴角勉强上扬，下眼睑发亮，笑声发虚 |
| 被戳穿 | 心虚 + 恐惧 | 视线闪开、眨眼变快、呼吸变浅、回答慢半拍 |
| 失控大哭 | 悲伤 + 崩溃 | 肩膀塌下、嘴唇抖、鼻音断续、手无力垂落 |
| 胜券在握 | 压迫感/强者平静 + 冷笑 | 少动、慢说、单侧嘴角、眼神稳定 |
| 社死后强装镇定 | 尴尬 + 隐忍 | 短笑收住、整理衣角、眼神找出口、声音压平 |
| 迟来的道歉 | 内疚/愧疚 + 温柔 | 靠近又停住、手掌半摊、声音变轻、尾音下落 |
| 被当众羞辱 | 羞耻 + 愤怒 | 低头、肩膀内扣、下颌绷紧、拳头松开又攥紧 |
| 劫后余生 | 恐惧 + 解脱 | 眼白未收、长呼气、肩膀沉下、手仍在轻抖 |
| 被突然点名后撑场 | 惊讶 + 临场撑住 | 眼神先停住、表情收回、重新找重心、语速刻意放稳 |
| 试探式告白前 | 心动克制 + 迟疑 | 视线停留后移开、手停半途、呼吸变浅、换成更安全措辞 |
| 说出真相但怕反击 | 防御性坦白 + 戒备 | 主动对视、手掌半摊、身体侧留退路、句尾发硬 |
| 商务场合被冒犯 | 强颜欢笑 + 隐忍 | 嘴角礼貌拉开、眼周不松、手指扣住杯沿、停顿后换更稳措辞 |
| 会议中掉线 | 厌倦/走神 + 临场撑住 | 身体先塌、视线离开，被点名后快速坐直、语速刻意恢复 |
| 惊喜不能露馅 | 压抑兴奋 + 心虚 | 眼睛发亮后移开、嘴角压住、手指多余整理、回答快半拍又收住 |
| 被突然逼问后慌乱遮掩 | 身体主导焦虑 + 心虚 | 衣领或袖口被抓紧、视线找出口、回答吞掉半句、呼吸短促 |
| 失恋后硬撑离开 | 沉重失落 + 强撑镇定 | 脚步拖慢但背重新挺住、声音压稳、手里物件低垂 |
| 闻到厌恶线索但保持礼貌 | 身体排斥 + 强颜欢笑 | 手掌向外挡又收回、身体侧开、嘴角礼貌拉开但眼神避开 |
| 被指出破绽后临时改口 | 被点破后自我修正 + 心虚 | 原动作撤回、快速眨眼、整理无关物、换成更安全短句 |
| 终于被看见但不敢接住 | 不敢相信的被认可 + 压抑兴奋 | 眼神回看证据、胸口慢慢打开、嘴角压住、声音轻而不稳 |
| 当众受压仍维持体面 | 公共场合被迫体面 + 隐忍 | 背挺直、礼貌笑保持、手压住桌沿、音量降低且语速放稳 |
| 接过烂摊子后强行扛住 | 被托付后责任落肩 + 临场撑住 | 肩膀先沉、背重新挺直、手握稳交付物、声音压实 |
| 听懂威胁但不接招 | 听懂潜台词后装作没听懂 + 戒备 | 眼神短扫线索、继续无关动作、身体侧留退路、回答短而轻 |
| 嘴硬接受照顾 | 被帮助时抗拒又软化 + 强颜欢笑 | 先挡开、后接住、嘴上轻描淡写、眼周和肩颈慢慢松开 |
| 当众被误会但不能吵 | 被误会后急于澄清又不能失态 + 公共场合被迫体面 | 身体先抢前又坐回、手停在胸前、语速被压慢、眼神仍追对方 |
| 爆发后立刻后悔 | 临时失控后迅速收回 + 内疚/愧疚 | 主动作命中后收手、避开现场证据、手指余抖、声音突然降低 |
| 怕也要做决定 | 终于下定决心但仍害怕 + 戒备 | 眼神从退路回到目标、重心压回、背挺住、手仍抓紧保护物 |
