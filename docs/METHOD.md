# 怎样使用表演可视化

创作意图先经过人物处境与目标，再转成可见反应：

```text
处境与目标 → 触发事件 → 判断或停顿 → 主动作 → 对方回应／环境反馈 → 结束状态
```

## 选择通道

眼神决定看什么、何时移开；呼吸决定动作是否被压住；手部与道具承担接触和犹豫；重心与身体形状表达靠近、退让或负荷；空间关系显示亲疏与控制；声音写可听的变化。

优先选择当前镜头能看见的通道。远景可以依靠轮廓、站位和步态；近景可借助视线、呼吸和手部停顿。选一个主动作和必要的辅助动作，不机械要求每段凑足通道数。

## 按内容类型转写

- **图片**：只保留一个瞬间可同时成立的姿态、接触点与空间关系。不要要求静态图片完成一串先后动作。
- **分镜**：注明触发、动作或反应的重点、人物站位、切点及结束状态。
- **视频**：保留动作先后、重量、回应与余波，结合镜头时长选择完整动作段。

## 按人物调整

同样的“焦虑”，可以表现为反复检查，也可以表现为刻意不动。条目是可选的表演方案，不能脱离性格、关系、文化和身体条件当作固定心理对应表。

先服从已确认的剧情、角色和资产条件，再改写条目中的姓名、物件和动作。不要因为示例用了杯子就向原场景凭空添加杯子。

当模型不支持声音时，把声音建议留给后续配音或剪辑，不把声音字段当作模型已有能力。身体表演清晰也不等于身份一致性、手部结构和物理连续性自动得到保证。
