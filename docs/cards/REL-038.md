# REL-038 · 空间层级中的权力切换

[返回索引](../INDEX.md) · [原始数据](../../cards/REL-038.json)

分类：人物关系 ｜ 更新：2026-10-02

## 使用要点

权力变化可以先发生在空间里；写清谁从中心变边缘、谁从门口进入光里，以及对方是否用身体承认新的位置。

## 可观察通道

- **old_map**：先建立原来的高低、远近、中心/边缘或门口/桌后等空间层级
- **shift**：一方通过靠近、退到边缘、占据中心或绕开障碍改变权力读法
- **acknowledgement**：另一方用视线跟随、让路、补位或保持原地来承认/抵抗变化

## 文字参考

他原本坐在桌后，灯光和文件都在他这边。她说完最后一句，没有提高声音，只绕过桌角站到窗前的亮处；他第一次没有继续翻文件，而是抬头跟着她的移动转身，椅背从屏障变成了退路。
