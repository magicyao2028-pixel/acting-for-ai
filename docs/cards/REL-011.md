# REL-011 · 失同步/关系裂缝

## 使用要点

用错开的停顿、未被接住的动作和扩大距离表现裂缝

## 可观察通道

- **initiator**：一方仍按原节奏靠近、递物或说话
- **responder**：另一方延迟回应、提前收身或拒绝接续动作

## 文字参考

他仍像往常一样把外套递过去，她的手却没有抬起，只在半拍后把身体侧开；外套悬在两人之间，他先收回视线，再慢慢收回手，原本相邻的站位空出一步距离。
