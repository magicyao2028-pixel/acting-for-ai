# MOT-036 · 主姿态与微手势分层

[返回索引](../INDEX.md) · [原始数据](../../cards/MOT-036.json)

分类：动作质感与节拍 ｜ 更新：2026-09-18

## 使用要点

先定一到两个主姿态承载核心情绪，再让手势、头眼和微停顿作为附着层，不要每句台词都换一个大姿态。

## 方法参考

复杂表演可以先锁主姿态，再叠加局部手势和节拍。主姿态负责情绪立场，微手势负责台词重音、转念和反应。

| 层级 | 写什么 | 作用 |
|---|---|---|
| 主姿态 | 身体朝向、重心、张力、与对象距离 | 观众一眼读到当前立场 |
| 支撑手势 | 肩、手、头的小幅动作 | 跟随台词重音或潜台词 |
| 微停顿 | 眼神定住、呼吸停半拍、手指迟疑 | 让思考过程可见 |
| 余波层 | 眨眼、眼跳、手指回收、衣物轻动 | 防止动作像机械切换 |

示例：她整场都保持身体微微侧向门口，表示想离开；只有在听见“留下”时，手指在包带上停半拍，眼神回到对方脸上，然后才慢慢松开包带。
