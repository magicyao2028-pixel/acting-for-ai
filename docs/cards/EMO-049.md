# EMO-049 · 信息砸中后的延迟反应

[返回索引](../INDEX.md) · [原始数据](../../cards/EMO-049.json)

分类：情绪与状态 ｜ 更新：2026-09-25

## 使用要点

不要直接写“震惊”；把信息进入身体的顺序写清楚：先注意、再处理、最后显露，让观众看到角色正在把事实吞下去。

## 可观察通道

- **notice**：眼神先落到触发物或说话者，身体暂时不跟上
- **process**：呼吸卡住半拍，肩颈或手指先泄露判断过程
- **reveal**：表情和身体再分开落地，形成“听见了”和“接受了”的时间差

## 文字参考

她听见名字后没有立刻回头，眼睛先停在杯沿上，指腹把杯壁按白了一瞬；半拍之后才抬眼看向门口，嘴角想撑住礼貌，却被一次没落下去的呼吸截断。
