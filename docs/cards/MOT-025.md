# MOT-025 · 预备动作的真假意图

## 使用要点

按当前镜头需要选用；保留动作因果、接触点和结束状态，不把全部动作规则同时堆进提示词。

## 方法参考

预备动作不是只为大动作蓄力，也可以承担悬念：观众以为人物要靠近、攻击或离开，下一拍才发现真实目标是递物、保护或退让。提示词必须写清预备动作和结果动作之间的可见关系。

| 用途 | 可见写法 | 避免 |
|---|---|---|
| 真实意图预告 | 眼神先落到目标，重心和手部都朝同一方向蓄力 | 大动作突然发生，没有起点 |
| 错误方向误导 | 身体先朝一个方向启动，主手或视线在最后一拍切到真实目标 | 无原因反转，像动作跳变 |
| 压住冲动 | 吸气和前倾已经出现，但手停住或改去整理道具 | 只写“忍住”，没有身体证据 |

示例：他看似要冲向门口，重心已经压到前脚掌，手也伸向门把；下一秒视线却落到她身后的窗帘，手从门把旁擦过，改为拉上窗帘挡住外面的视线。
