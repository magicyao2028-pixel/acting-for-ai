# REL-034 · 主动让出焦点/替人卸压

## 使用要点

让出焦点要写视线如何被转移，以及被保护者如何借空隙恢复；不要只写“帮她解围”。

## 可观察通道

- **initiator**：察觉对方被看住后，主动降低动作幅度、移开站位或把观众视线引向安全对象
- **responder**：对方先从紧绷中恢复呼吸，再用更小动作重新进入场面

## 文字参考

众人都看向她时，他没有替她解释，只把椅子轻轻拉响半寸，身体侧到灯下接住视线，低声说“先看这份记录”。她借这一瞬低头吸气，把僵住的手慢慢放回桌面。
