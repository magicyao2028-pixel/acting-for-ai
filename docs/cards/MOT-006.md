# MOT-006 · 心理手势转提示词

[返回索引](../INDEX.md) · [原始数据](../../cards/MOT-006.json)

分类：动作质感与节拍 ｜ 更新：2026-09-04

## 使用要点

按当前镜头需要选用；保留动作因果、接触点和结束状态，不把全部动作规则同时堆进提示词。

## 方法参考

心理手势只用于内部提炼角色核心，不要求人物在镜头里做夸张符号动作。落到提示词时，保留“姿态残留”和“行为倾向”。

| 内部核心手势 | 镜头内可见残留 | 适用提示词 |
|---|---|---|
| 推开 | 手掌停在身体前方，胸口与对方保持距离 | 角色想拒绝、保护边界、压住靠近冲动 |
| 抓住 | 手指反复收紧，道具被扣住，视线不肯离开目标 | 角色执念、占有、害怕失去 |
| 托起 | 手掌向上，动作放慢，身体靠近但不逼迫 | 安抚、请求、交出真相 |
| 砸下 | 肩颈蓄力，手或物件重重落点，余波留在胸口 | 决断、爆发、断关系 |
| 包裹 | 手臂靠近身体或护住某物，声音变低 | 保密、愧疚、珍惜、隐藏伤口 |

模板：`先用一个内部动词锁定角色冲动，再把它拆成[重心方向 + 手部残留 + 视线目标 + 声音质感]，避免让演员做符号化大动作。`
