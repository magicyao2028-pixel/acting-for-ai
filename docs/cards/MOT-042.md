# MOT-042 · 呼吸先行的台词和动作准备

## 使用要点

重要台词或动作前，先写身体如何吸气、停气、放气或重新找支撑；呼吸变化能把情绪、声音和动作目标连起来。

## 方法参考

把呼吸作为动作链第一拍，而不是额外气氛词。

| 呼吸状态 | 提示词写法 | 适用场景 |
|---|---|---|
| 吸气未完成 | 话到嘴边先吸住一口气，肩膀微微提起 | 想说又不敢说 |
| 放气后开口 | 先把胸口那口气慢慢吐掉，再低声回答 | 强行镇定、让步 |
| 呼吸找支撑 | 脚跟站稳，肋侧扩开后再抬声 | 宣布决定、压住场面 |
| 呼吸被打断 | 刚吸进去的气停在喉咙，手上的动作漏半拍 | 被消息击中、被误会 |
