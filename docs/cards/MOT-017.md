# MOT-017 · 激烈动作中的台词呼吸

[返回索引](../INDEX.md) · [原始数据](../../cards/MOT-017.json)

分类：动作质感与节拍 ｜ 更新：2026-09-04

## 使用要点

按当前镜头需要选用；保留动作因果、接触点和结束状态，不把全部动作规则同时堆进提示词。

## 方法参考

人物边跑、打斗、搬东西、挣扎或哭笑边说话时，台词不能像静坐朗读。每句台词需要绑定呼吸位置、身体负荷和动作停顿。

| 场景 | 风险 | 修正写法 |
|---|---|---|
| 奔跑中解释 | 口型太稳，身体负荷缺失 | 他边跑边回头，话被脚步切成短句；每跨过一级台阶都先吸气，最后几个字几乎从喘息里挤出 |
| 推搡中争吵 | 台词和动作互不影响 | 她被推到墙边后先撞停，下一句没有立刻出口；胸口起伏两下后，声音突然压低，手掌撑墙稳住身体 |
| 哭笑转换 | 声音情绪同拍跳变 | 她笑声先断在喉咙里，吸气没有接上，嘴角还挂着笑，眼泪却先滚下来；下一句变成带鼻音的低声 |
