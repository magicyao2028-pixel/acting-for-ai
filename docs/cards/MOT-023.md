# MOT-023 · 静止与动作对比

## 使用要点

按当前镜头需要选用；保留动作因果、接触点和结束状态，不把全部动作规则同时堆进提示词。

## 方法参考

静止不是空白，而是人物正在压住、判断或等待对方反应。视频提示词可用短静止建立节奏，再让动作命中。

| 用途 | 可见写法 | 避免 |
|---|---|---|
| 压住情绪 | 身体停住，只有胸口、指尖或下颌保留微动 | 全身僵死、无呼吸 |
| 等待对方接招 | 递物或问题抛出后动作停在可接位置，视线不催促 | 说完立刻换动作 |
| 转念前留白 | 旧动作悬停，眼神重新定点，短吸气后进入新动作 | 情绪秒切 |
| 爆发后收束 | 主动作结束，余波留在肩颈、衣角、道具震动或呼吸 | 动作落点后立刻切无余波 |

示例：她把问题说完后没有继续逼近，手停在桌面边缘，眼神稳稳等对方先动；半秒静止后，对方先移开视线，她才把文件推过去。
