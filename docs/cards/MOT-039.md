# MOT-039 · 真实环境压力下的动作连续性

[返回索引](../INDEX.md) · [原始数据](../../cards/MOT-039.json)

分类：动作质感与节拍 ｜ 更新：2026-10-02

## 使用要点

角色穿过狭窄、杂乱或有障碍的环境时，要写身体如何预判、避让、接触和恢复；不要只写“穿过房间”。

## 方法参考

把环境压力拆成连续动作：先感知障碍，再改变路径或姿态，接触后出现重量/阻力反馈，最后恢复主目标。

| 压力点 | 提示词写法 | 作用 |
|---|---|---|
| 预判 | 眼神先扫到窄门，肩膀提前收紧 | 让角色意识到环境 |
| 接触 | 袖口擦到门框，手背顺势按住墙面 | 让空间有物理存在 |
| 修正 | 脚步短暂停住，重心换到另一侧再通过 | 避免漂浮穿模感 |
| 恢复 | 通过后才重新抬头说话或加速 | 保持动作目标连续 |

示例：她抱着箱子挤过走廊时先把箱角往胸前收，肩膀贴着墙慢慢侧过去；箱底磕到门框，她停半拍换手托住，确认没有掉落后才继续追上前面的人。
