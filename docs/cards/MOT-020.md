# MOT-020 · 景别尺度与表演幅度

## 使用要点

按当前镜头需要选用；保留动作因果、接触点和结束状态，不把全部动作规则同时堆进提示词。

## 方法参考

同一表演要按景别换通道。远景优先身体轮廓、路线和距离；中景平衡身体与手势；近景压低大动作，强调眼神、呼吸、指尖和嘴角。

| 景别 | 优先通道 | 提示词约束 |
|---|---|---|
| 全景/远景 | 站位、身体形状、步幅、路线、群体朝向 | 加大轮廓变化，写清靠近/远离/绕开/下沉，避免只写眉眼 |
| 中景 | 重心、胸口朝向、手势、道具、眼神目标 | 主手势必须落在镜头可读区域，辅助手晚半拍，不同时抢动作 |
| 近景/特写 | 眼跳、眨眼、嘴角、下颌、呼吸、指尖 | 减少大幅转身和挥手，用微停顿、吞咽、短吸气表现转念 |
