# REL-040 · 独立任务被关系侵入

[返回索引](../INDEX.md) · [原始数据](../../cards/REL-040.json)

分类：人物关系 ｜ 更新：2026-10-09

## 使用要点

当人物带着任务对话时，不要让任务消失；让对方的存在改变任务的速度、准确度或力度，关系压力就会被看见。

## 可观察通道

- **split_attention**：角色在任务与关系之间分配注意，回应变慢、动作漏拍或任务出错
- **intrusion**：另一人用问话、靠近、敲门或沉默持续打进任务节奏
- **task**：先建立角色正在完成的具体、可见且有难度的任务

## 文字参考

她一边给伤口打结一边数着绷带圈数，他却站在门口反复问“你到底去哪了”。她没有抬头，只把最后一圈绕得太紧，病人吸了口凉气；她这才停住手，像是关系终于挤进了她正在做的事里。
