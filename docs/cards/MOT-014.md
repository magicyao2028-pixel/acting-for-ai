# MOT-014 · 镜头内身体路径

[返回索引](../INDEX.md) · [原始数据](../../cards/MOT-014.json)

分类：动作质感与节拍 ｜ 更新：2026-09-04

## 使用要点

按当前镜头需要选用；保留动作因果、接触点和结束状态，不把全部动作规则同时堆进提示词。

## 方法参考

| 路径 | 适用情境 | 提示词表达 |
|---|---|---|
| 直线逼近 | 压迫、质问、攻击 | 重心直接压向对方，步伐少但每一步都缩短距离 |
| 侧身绕开 | 心虚、回避、试探 | 肩膀先侧开，视线绕过对方，身体给门口留出角度 |
| 下沉停住 | 羞耻、崩溃、认输 | 肩膀和头慢慢垂下，声音落低，手无力停在身体前 |
| 向外打开 | 和解、解脱、坦白 | 胸口打开，手掌摊开，呼吸从喉咙落回胸腔 |
| 收紧蓄力 | 愤怒、恐惧、忍耐 | 下颌绷住，肩颈变硬，手指先收紧再触发主动作 |
