# MOT-037 · 双人协作搬运的重量同步

[返回索引](../INDEX.md) · [原始数据](../../cards/MOT-037.json)

分类：动作质感与节拍 ｜ 更新：2026-09-25

## 使用要点

两个人共同搬运、扶起或递交不可见/可见物件时，先统一重量、重心和发力顺序，再写关系分歧；不要让两人的身体各演各的。

## 方法参考

把协作动作写成共同物理问题：谁先试重量，谁调整握点，谁承担主要负重，谁在失衡时补一小步。

| 同步点 | 提示词写法 | 作用 |
|---|---|---|
| 试重量 | 两人先同时下沉肩膀，手腕微调后才抬起 | 让物件有真实重量 |
| 分担差异 | 一人身体更低、更慢，另一人不断回头等他 | 暴露体力、地位或照顾关系 |
| 失衡修正 | 物件一侧下坠，另一人立刻补步托住 | 让合作有事件感 |
| 情绪叠加 | 嘴上争执，手上仍保持同一节奏 | 表达冲突中仍必须协作 |

示例：两人合力抬起旧箱子，她先试着提，箱子一侧沉下去；他没有说话，只把手换到箱底，膝盖跟着下沉半拍，等她点头后两人才一起往门口挪。
