# REL-037 · 多人焦点接力/谁接住下一拍

[返回索引](../INDEX.md) · [原始数据](../../cards/REL-037.json)

分类：人物关系 ｜ 更新：2026-10-02

## 使用要点

多人同场不要让所有人同时抢戏；给每个焦点转移写一个可见的“接住”和“让出”，让群戏像接力而不是噪音。

## 可观察通道

- **current_focus**：先写清当前谁拥有观众注意力，以及其他人如何降低动作幅度
- **take**：下一人用一个明确动作、声音或移动理由接过焦点
- **give**：原焦点人物用停住、让开、转视线或收小动作把中心交出去

## 文字参考

饭桌上的争吵刚压住，父亲还握着杯子没放下。妹妹忽然把椅子往后一拖，所有人的视线都被那一下带过去；父亲没有追话，只把杯子轻轻放回桌面，像是把这一拍让给她。
