# REL-036 · 空间补位/关系被重新定义

[返回索引](../INDEX.md) · [原始数据](../../cards/REL-036.json)

分类：人物关系 ｜ 更新：2026-09-25

## 使用要点

关系改变可以先通过站位发生；写清原来的空间逻辑、谁改变位置、对方怎样接受或拒绝新的画面。

## 可观察通道

- **old_relation**：先保留原关系的距离、朝向或障碍物
- **new_position**：一人不解释，只用补位、转身、靠近或隔开重新定义关系
- **response**：对方用微退、停住、让出空间或同步朝向承认新关系

## 文字参考

她原本站在两人之间，像一道临时的墙。听见那句“让他说完”后，她没有争辩，只向旁边退开半步，把空位留给他；他迟疑了一下，终于从门边走进光里，和她站成同一方向。
