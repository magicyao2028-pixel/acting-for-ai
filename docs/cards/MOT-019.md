# MOT-019 · 眨眼/眼跳作为思考剪辑

## 使用要点

按当前镜头需要选用；保留动作因果、接触点和结束状态，不把全部动作规则同时堆进提示词。

## 方法参考

眼睛不是均匀活动的装饰。眨眼、眼跳和定焦应放在想法变化、快速转头、发现线索、遮掩情绪或决定行动的节点上。

| 节点 | 可见规则 | 提示词写法 |
|---|---|---|
| 想法转向 | 旧视点结束前短眨，睁眼后落到新目标 | 他听到那个名字时先眨了一下，睁眼后视线不再看她，而是落到门边的鞋印 |
| 搜索线索 | 多个短眼跳之间保留定焦，不让眼神全程乱飘 | 她的视线先扫过桌面、照片和杯沿，每次都短暂停住，最后钉在那枚指纹上 |
| 快速转头 | 眼睛先动，头跟随，眨眼压在转头中段或末端 | 门外一响，他的眼睛先切向声源，头部快速跟上，眨眼落在转头快结束时 |
| 情绪遮掩 | 眨眼后表情重组，手或身体同时做遮掩动作 | 她被问到日期时眨了一下，笑容重新挂回脸上，手却把票根压进掌心 |
