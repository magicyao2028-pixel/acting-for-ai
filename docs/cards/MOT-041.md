# MOT-041 · 重复动作逐次变义

[返回索引](../INDEX.md) · [原始数据](../../cards/MOT-041.json)

分类：动作质感与节拍 ｜ 更新：2026-10-09

## 使用要点

同一个词、手势或移动重复出现时，每次都要改变持续时间、力度或收尾，让观众看到意义从确认、逼迫、动摇到放弃的变化。

## 方法参考

重复不是机械复制，而是让同一动作在时间里改变含义。停住-重复-变形-放弃/爆发 可以成为短视频表演节拍。

| 次数 | 提示词写法 | 观众读法 |
|---|---|---|
| 第一次 | 她轻轻敲了两下门，停住听里面的动静 | 试探 |
| 第二次 | 敲门变成三下，指节更重，身体往门缝靠近 | 逼近 |
| 第三次 | 手抬起来却没落下，掌心慢慢贴在门上 | 意识到对方不会回应 |
| 收尾 | 她把手放下，退半步看向走廊尽头 | 放弃或换策略 |
