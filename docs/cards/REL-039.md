# REL-039 · 倾听时被对方改变

[返回索引](../INDEX.md) · [原始数据](../../cards/REL-039.json)

分类：人物关系 ｜ 更新：2026-10-09

## 使用要点

写对话关系时，不要让下一句像预装回复；让角色先被对方的具体行为影响，再从改变后的身体状态里回应。

## 可观察通道

- **alteration**：身体出现被影响后的微小变化，如坐姿松开、手停住、视线改落点
- **receive**：先让角色真正接收对方的动作、语气或停顿
- **answer**：回应不是预设台词，而是从这个变化后的状态发出

## 文字参考

他说完以后，她没有马上接自己的台词，先看见他握杯子的手在抖。她原本交叉的手臂慢慢松开，视线从他的脸落到杯沿，再回到他眼睛里；开口时声音低了一格，像是被那一下抖动改了路线。
