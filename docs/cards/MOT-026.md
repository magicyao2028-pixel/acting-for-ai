# MOT-026 · 无实物动作连续性

## 使用要点

按当前镜头需要选用；保留动作因果、接触点和结束状态，不把全部动作规则同时堆进提示词。

## 方法参考

无实物表演或 AIGC 道具不稳定时，动作要靠身体逻辑成立。写清接触高度、手指压力、重量变化、阻力方向和结束位置，减少模型把手势做成空挥。

| 动作 | 连续性检查 | 提示词写法 |
|---|---|---|
| 拿起不存在或不稳定的物件 | 手先贴近接触点，手指合拢后重量进入手腕 | 她的手先贴到桌面边缘，指尖像扣住薄纸一样收紧，手腕慢半拍抬起，纸张重量带着手指轻颤 |
| 推开空气中的阻碍 | 肩肘腕按顺序发力，身体给出反作用 | 他先把肩膀压上去，肘部随后伸直，掌心像顶住一扇沉门，脚跟在地面稳住后门才被推开 |
| 藏起小物件 | 视线先确认第三方，手掌闭合后贴回身体 | 她先扫了一眼旁边的人，指尖合拢把票根扣进掌心，手背贴回杯子旁，动作恢复成倒水 |
