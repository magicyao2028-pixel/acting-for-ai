# MOT-012 · 行动动词转提示词

## 使用要点

按当前镜头需要选用；保留动作因果、接触点和结束状态，不把全部动作规则同时堆进提示词。

## 方法参考

表演提示词优先使用“可执行动词”，再落到空间、手部、声音和余波。

```text
人物目标：[想让谁发生什么变化]
阻碍：[对方/环境/心理卡点]
策略动词：[讨好/逼问/遮掩/引诱/威胁/求证/安抚/退让]
可见化：[距离变化 + 手部动作 + 视线目标 + 声音质感 + 余波]
```

示例：`她想让对方留下，但自尊挡住了直接挽留；她没有拉住他，只把钥匙压在掌心，站在门边挡住半个出口，声音放低，最后一个字落下后仍看着他的背影。`
