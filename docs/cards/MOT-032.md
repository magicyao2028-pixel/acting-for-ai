# MOT-032 · 不可见关键物件的在场维持

[返回索引](../INDEX.md) · [原始数据](../../cards/MOT-032.json)

分类：动作质感与节拍 ｜ 更新：2026-09-11

## 使用要点

按当前镜头需要选用；只为关键物件保留在场提醒，次要物件用完即可退出焦点。

## 方法参考

当道具不可见、生成不稳定或镜头暂时离开道具时，要用身体关系维持它的存在感，而不是反复口头说明。

| 场景 | 可见写法 | 避免 |
|---|---|---|
| 关键物件离手后仍在场 | 人物离开后偶尔用余光、身体绕行或手势避让提醒它的位置 | 物件用完后完全消失，下一拍突然又被拿起 |
| 远距离看见屏幕/物体 | 先建立视线落点，再用身体反应或简短模仿显示看到的内容 | 只写“他看见某物”，没有观众可读线索 |
| 多人共享不可见物件 | 每个人接触同一高度、重量和方向，交接时保留手腕受力 | 交接前后尺寸和重量变化 |

示例：她把不存在的首饰盒放到桌面右角后退开，肩膀仍绕开那一小块空间；说话时余光隔几秒轻轻落回盒子位置，直到他伸手时，她先看见手快碰到盒角，身体立刻前倾拦住。
