# MOT-007 · 一拍一意图

分类：动作质感与节拍 ｜ 更新：2026-09-04

## 使用要点

按当前镜头需要选用；保留动作因果、接触点和结束状态，不把全部动作规则同时堆进提示词。

## 方法参考

动画和影视表演都需要清晰调度。一个镜头节拍只让观众读一个主要意图；次动作只能帮助主意图，不和主意图抢焦点。

| 问题 | 风险 | 修正写法 |
|---|---|---|
| 同一拍同时哭、笑、后退、拿道具、转头 | 模型会平均化动作，表演变乱 | 先写触发点，再写一个主动作，最后补一个余波动作 |
| 表情和身体说不同意思但没有原因 | 容易被识别为跑偏或表情错位 | 明确这是潜台词：嘴上礼貌，手先压住钥匙 |
| 群体镜头每个人都在动 | 关系焦点散掉 | 主角先动，其他人用视线、停顿或小范围反应围住主角 |
| 大动作没有预备和收束 | 动作像剪切跳变 | 加入吸气、重心改变、头发衣角或手指余波 |
