# EMO-046 · 被迫等待消息时强装无事

## 使用要点

等待要写外部触发、强装正常和漏出的微小节奏差；不要只写“焦急”。

## 可观察通道

- **face**：眼神反复扫向消息来源又迅速移开，笑容维持在社交幅度内
- **body_hands**：手上的日常动作继续进行，但节奏被通知声、脚步声或他人视线打断
- **voice**：回答比平时快半拍，句尾轻轻压住，不让旁人听出急迫

## 文字参考

她一边把杯子摆回托盘，一边用余光扫向亮起的手机；同事看过来时她立刻抬头笑了一下，手继续擦桌面，只是抹布在同一个位置多停了两下。
