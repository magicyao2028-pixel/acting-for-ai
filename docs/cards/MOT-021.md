## 使用要点

按当前镜头需要选用；保留动作因果、接触点和结束状态，不把全部动作规则同时堆进提示词。

## 方法参考

不要把 Laban 术语直接输出给用户；内部只用它把“怎么动”压成可执行的重量、方向和时间。

| 质感 | 内部组合 | 提示词写法 |
|---|---|---|
| Punch / 冲击 | 重、直、快 | 他一步直压过去，手掌重重按上桌面，停顿短而硬 |
| Press / 压迫 | 重、直、慢 | 她慢慢逼近，手指持续压住文件边缘，声音低而稳 |
| Flick / 甩开 | 轻、绕、快 | 他把视线轻快甩开，指尖快速掸过袖口，像不愿被话题沾住 |
| Wring / 拧绞 | 重、绕、慢 | 她双手反复拧着包带，肩膀向里卷，句子拖慢又说不完整 |
| Glide / 滑行 | 轻、直、慢 | 他平稳走近，步幅轻而连续，视线始终锁在目标上 |
