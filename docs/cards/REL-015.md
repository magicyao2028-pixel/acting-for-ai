# REL-015 · 被围观/观演压力

## 使用要点

写观众视线、主角重心和声音变化；被围观感不能只靠“尴尬”

## 可观察通道

- **initiator**：围观者形成视线压力、身体朝向主角
- **responder**：被看见者表情管理变强，动作变小或突然放大

## 文字参考

周围人的视线一层层压过来，她原本要抬起的手停在胸前，笑容被硬撑住；下一秒她把背挺直，音量比刚才低半级，像是在所有人面前把狼狈收回去。
