# MOT-022 · 黄金姿态与剪影可读性

## 使用要点

按当前镜头需要选用；保留动作因果、接触点和结束状态，不把全部动作规则同时堆进提示词。

## 方法参考

关键帧或分镜提示词不要只堆面部细节。先让身体轮廓在当前镜头角度能读出主意图，再补眼神、手势和道具。

| 检查点 | 风险 | 修正写法 |
|---|---|---|
| 手势埋在身体内侧 | 观众看不清角色正在抓、挡、递还是藏 | 把主手势放到身体外轮廓或前景道具边缘，让手与脸之间留出可读空隙 |
| 身体完全竖直对称 | 姿态像站桩，情绪和力量方向不清 | 让肩线、髋线或脊柱形成轻微反向倾斜，重心明确落到一只脚 |
| 受力动作只有表情 | 重量和阻力缺失，动作像摆姿势 | 写脚下支撑、髋部转向、背部弧线和手指压力，让身体对抗具体重量或人 |
| 群体姿态焦点散 | 每个人都在抢动作，主角意图变弱 | 主角形成最清晰剪影，其他人用朝向、视线和小幅停顿围住主角 |

提示词模板：`关键帧保持一个清晰剪影：[主角重心/脊柱方向/主手势位置]先读出[意图]；脸部和道具作为第二层证据，不遮住主动作。`
