# MOT-035 · 动作节奏纹理/停顿快切

[返回索引](../INDEX.md) · [原始数据](../../cards/MOT-035.json)

分类：动作质感与节拍 ｜ 更新：2026-09-18

## 使用要点

同一动作不要匀速到底；用短停、预备、快速命中和收束余波制造情绪节奏。

## 方法参考

把动作写成节奏，而不是连续说明。先决定哪一拍需要观众读懂，哪一拍需要爆发或切断。

| 节奏功能 | 提示词写法 | 适用 |
|---|---|---|
| 黏住悬停 | 动作停在半空，呼吸压住，下一拍突然落下 | 犹豫、威胁、喜剧反差 |
| 快速命中 | 预备很短，主动作干脆，落点清楚 | 决断、攻击、抢答 |
| 慢预备快释放 | 先聚气/聚焦/握紧，再突然完成动作 | 怒意、突破、压抑爆发 |
| 爆发后余波 | 主动作结束后保留衣角、道具、胸口起伏 | 后悔、惊吓、强烈转折 |

示例：他抬手要敲门，指节停在门板前半寸，呼吸悬住；下一秒连续敲两下，敲完手仍贴在门上，没有立刻放下。
