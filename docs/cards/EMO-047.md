# EMO-047 · 被权威认可后仍保持低姿态

[返回索引](../INDEX.md) · [原始数据](../../cards/EMO-047.json)

## 使用要点

认可后的喜悦和地位压力要同时存在：先让身体露出被看见，再让角色主动收住。

## 可观察通道

- **face**：眼睛先亮起又压回平静，嘴角只短暂上扬
- **body_hands**：身体想前倾接住认可，随后把肩颈和手势收回原本位置
- **voice**：先轻声确认，再用简短回应把场面还给对方

## 文字参考

听见老师当众点头后，他的眼睛先亮了一瞬，手指已经要松开本子；下一秒他把本子贴回胸前，微微低头，只说了一句“我再改一版”，站位仍留在队伍边缘。
