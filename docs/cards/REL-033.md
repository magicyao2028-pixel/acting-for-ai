# REL-033 · 替对方留台阶

## 使用要点

留台阶要写被救场者如何接住；不要把关系写成单方面善意说明。

## 可观察通道

- **initiator**：发现对方失误后，不直指错误，而是用站位、道具或话题制造可退路径
- **responder**：对方先停住尴尬动作，再顺着新路径把姿态恢复正常

## 文字参考

他看见她把名字叫错，没有纠正，只把签到表往她手边轻轻一推，语气自然地问“要不要再核一下顺序”。她的手停了一瞬，顺势低头看表，把刚才扬起的笑慢慢收成工作状态。
