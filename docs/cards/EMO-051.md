# EMO-051 · 被打断后把情绪咽回去

[返回索引](../INDEX.md) · [原始数据](../../cards/EMO-051.json)

分类：情绪与状态 ｜ 更新：2026-10-09

## 使用要点

被打断不是简单“停住”；写清外部刺激如何截断情绪、身体如何把反应吞回去，以及角色把注意力转移到哪个更安全的动作上。

## 可观察通道

- **redirect**：下一拍改用更安全的任务、表情或话题继续场面
- **trigger**：外部声音、敲门、对方插话或新动作打断原本情绪
- **swallow**：角色先停止当前动作，呼吸或喉结把情绪压回去

## 文字参考

她刚要把那句话说出口，门外忽然响起敲门声。她的下巴停在半空，眼眶里的热意没有落下来，只把杯子往自己这边收了收；等门把手转动时，她已经换成平静的坐姿，像刚才什么都没发生。
