## 使用要点

按当前镜头需要选用；保留动作因果、接触点和结束状态，不把全部动作规则同时堆进提示词。

## 方法参考

参考 Laban 的 Body / Space / Shape / Effort 分层时，只取可见动作，不输出理论名词。

| 身体变化 | 适用状态 | 提示词写法 |
|---|---|---|
| 收拢 / 包住自己 | 羞耻、防御、恐惧、保密 | 肩膀向里收，手臂靠近身体，胸口变窄，声音从身体里压出来 |
| 展开 / 占据空间 | 坦白、胜利、控场、释放 | 胸口打开，手掌离开身体，站位变宽，视线不再躲闪 |
| 上升 / 重新站稳 | 决心、反击、恢复尊严 | 重心从脚跟推回脚掌，背慢慢挺直，头最后抬起 |
| 下沉 / 放弃抵抗 | 认输、崩溃、疲惫、失望 | 膝盖松掉一点，肩膀和头一起沉下，手里的物件被放低 |
| 前进 / 夺回主动 | 质问、追问、求证、保护 | 先把重心压向目标，再缩短距离，手势明确指向对方或证据 |
| 后撤 / 保留退路 | 心虚、戒备、试探、被压迫 | 身体侧开半步，视线仍留在对方身上，脚尖先指向出口 |
