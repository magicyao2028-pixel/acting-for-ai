# MOT-009 · 动作节拍拆法

[返回索引](../INDEX.md) · [原始数据](../../cards/MOT-009.json)

分类：动作质感与节拍 ｜ 更新：2026-09-04

## 使用要点

按当前镜头需要选用；保留动作因果、接触点和结束状态，不把全部动作规则同时堆进提示词。

## 方法参考

| 节拍 | 提示词问题 | 可见写法 |
|---|---|---|
| 听见/看见 | 哪个刺激打到人物 | 眼神突然停住、手上动作中断、呼吸漏一拍 |
| 消化 | 人物先压住还是先泄出 | 下颌收紧、眨眼变快、肩膀僵住、短暂沉默 |
| 选择 | 人物决定靠近、回避、攻击还是求和 | 重心前移、身体侧开、手掌打开、拳头收紧 |
| 执行 | 主动作如何发生 | 一步逼近、慢慢坐直、把物件放下、抬眼盯住 |
| 余波 | 动作结束还剩什么 | 胸口起伏、手指还在抖、笑意收不干净、房间安静下来 |
