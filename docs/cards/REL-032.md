# REL-032 · 无词确认关系

## 使用要点

用可见邀请和回应建立关系；无词不是无事发生，必须有动作被对方读到并改变下一拍。

## 可观察通道

- **initiator**：一方先给出可接的物件、站位或眼神等待，不用解释关系
- **responder**：另一方通过是否接住、靠近、避开或同步动作确认当前关系
