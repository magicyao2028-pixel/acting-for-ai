# MOT-033 · 预备动作按景别缩放

[返回索引](../INDEX.md) · [原始数据](../../cards/MOT-033.json)

## 使用要点

按镜头景别决定预备动作幅度；同一个意图在远景、中景和近景不能写成同一组动作。

## 方法参考

预备动作要让观众读到方向、力度和决定，但幅度必须服务当前景别。

| 景别 | 更容易读到的预备动作 | 提示词写法 |
|---|---|---|
| 远景/全身 | 剪影、重心、躯干方向、步幅变化 | 先让重心压到前脚掌，肩线转向目标，再启动大步靠近 |
| 中景 | 身体力学加头眼目标 | 眼神先定到门把，肩膀微微预转，手随后伸出 |
| 近景 | 眼、呼吸、手指、肩颈小幅变化 | 指尖先收紧，短吸气后停半拍，再把信封推过界线 |

示例：同样是“决定离开”，远景写脚步和身体路线，中景写头眼与肩线先转向门口，近景只保留手指松开杯沿、吸气和视线离开对方。
