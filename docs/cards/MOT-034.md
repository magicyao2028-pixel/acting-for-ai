# MOT-034 · 道具关系暴露意图

[返回索引](../INDEX.md) · [原始数据](../../cards/MOT-034.json)

分类：动作质感与节拍 ｜ 更新：2026-09-18

## 使用要点

道具不只说明场景；要写角色如何拿、护、避开、递出或放下它，让物件关系替人物意图说话。

## 方法参考

道具可承担人物目标、隐瞒、冲突或过往关系。写提示词时先确定物件在这场戏里的功能，再安排手部、视线和身体距离。

| 物件功能 | 可见动作 | 避免 |
|---|---|---|
| 想隐藏 | 手掌盖住、身体挡住、说话时把物件推到阴影里 | 只写“他很心虚” |
| 想交出 | 物件停在可接距离，手指仍舍不得松开 | 递完立刻无反应 |
| 想占有 | 拿近胸口、随对方靠近而后撤 | 只写“珍贵道具” |
| 想切断 | 放下时让接触点清楚断开，视线随物件离开 | 道具突然消失 |

示例：她说自己已经放下，却把旧钥匙攥在掌心，指节泛白；当对方伸手时，她先把钥匙推到桌面中央，手指仍压着钥匙圈半拍才松开。
