# REL-019 · 同动作不同关系

## 使用要点

不只写“递东西”；写递到哪里、停多久、对方是否接、身体边界是否被允许

## 可观察通道

- **initiator**：同一动作在亲密、陌生、权威关系中改变边界
- **responder**：接收方用是否接住、是否后撤、是否回看标明关系

## 文字参考

她把外套递给朋友时手直接越过桌角，朋友自然接住；轮到主管走近，她把外套先放在椅背上，手离开后才开口提醒，对方只点头没有回看她。
