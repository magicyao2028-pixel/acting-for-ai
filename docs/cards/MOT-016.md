# MOT-016 · 低面部依赖的全身表演

[返回索引](../INDEX.md) · [原始数据](../../cards/MOT-016.json)

分类：动作质感与节拍 ｜ 更新：2026-09-04

## 使用要点

按当前镜头需要选用；保留动作因果、接触点和结束状态，不把全部动作规则同时堆进提示词。

## 方法参考

当脸部被墨镜、口罩、背光、远景、侧脸或快速动作削弱时，不要强行依赖微表情。让身体轮廓、肩背、脊柱、手脚、道具和节奏先承担情绪。

| 情境 | 可见替代通道 | 提示词写法 |
|---|---|---|
| 看不清眼睛但情绪要读懂 | 头部高度、肩背开合、手部压力、步幅节奏 | 墨镜遮住眼睛，但他走路的节奏很松，肩膀随着音乐轻晃，手指在车钥匙上敲出稳定节拍 |
| 远景人物情绪 | 身体剪影、胸口方向、手脚是否收紧 | 她站在走廊尽头，整个人缩成窄窄的轮廓，手臂贴住身体，脚尖始终偏向出口 |
| 背身反应 | 头颈停顿、肩膀变化、手里物件反馈 | 他背对镜头听完那句话，肩膀先停住，手里的纸杯被捏出一道凹痕，过了半秒才转身 |
